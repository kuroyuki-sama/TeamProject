# TeamProject
비판적사고 2팀 팀프로젝트용 리포짓

### 프로젝트 개요
- 1.1 프로젝트 제목 및 개요
    - 제목 : 스마트 리마인더
      - 사용자가 일상생활에서 발생하는 다양한 일정과 해야 할 일을 효율적으로 관리할 수 있도록 지원하는 일정 관리 프로그램이며, 사용자는 일정의 제목, 날짜, 시간, 상세 내용과 우선순위를 등록 할 수 있으며 등록된 일정을 시간 순이나 우선 순위로          확인하고 수정하거나 삭제 할 수 있다. 또한 지정된 시간이 되면 알림을 제공하고 반복 일정 및 완료 여부를 관리하여 중요한 일정이나 마감일을 놓치지 않도록 돕는 소프트웨어이다.

- 1.2 개발 동기 및 필요성
    - 학업, 업무, 개인 생활 등 다양한 일정을 관리하면서 중요한 약속이나 해야 할 일을 잊어버리는 경우가 많은데 이러한 문제를 해결하기 위해 일정 등록 및 조회, 시간 알림, 우선순위 설정 등의 기능을 제공하는 리마인더 프로그램을 개발하고자 합니다.
      이를 통해서 일정 관리의 효율성을 높이고 사용자가 보다 체계적이고 계획적인 생활을 할 수 있도록 하기 위해서이다.

- 1.3 프로젝트 목표
    - 우선순위 설정 넣기 <- 중요도 자동 정렬 기능
    - 반복 일정 기능 및 반복 일정 자동 생성 
    - 완료 체크 및 일정 완료율 분석 기능
    - 검색 기능
    - 일정 통계 및 일정 충돌 기능
    - 마감 임박(카운트다운 기능) 기능 및 미완료 일정 자동 이월 기능
    - 알림 기능
    - 일정 카테고리 기능
